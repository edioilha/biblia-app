# Architecture Decision Records (ADR)

Registro das decisões arquiteturais relevantes, no formato [MADR](https://adr.github.io/madr/) simplificado.

## Como usar

1. Copie [`template.md`](template.md) para `NNNN-titulo-curto.md` (próximo número).
2. Preencha e abra um PR com status **Proposta**.
3. Ao aprovar o PR, mude o status para **Aceita**.
4. Uma ADR **não é editada** depois de aceita: se a decisão mudar, crie uma nova ADR e marque a antiga como **Substituída por NNNN**.
